Nithish portfolio
1. Save these 5 files together in D:\Nithish-Portfolio\ : index.html, styles.css, app.js, content.js, avatar3d.js
2. Double-click index.html to open it.
3. Edit ONLY content.js to change text (email, LinkedIn, GitHub, resume link, project results, skill levels,
   the words that type out on the home screen, the CV summary).
4. Please check the Tamil, Hindi and Nepali spellings in content.js before publishing.
5. Education currently says "VIT Vellore, Graduate". Add your branch and graduation year in content.js if you want them shown.

What is on the site
- Intro: a short wake-up animation once per visit (click, Enter or "Skip intro" to skip).
- Embers: sparks drift behind the content, dodge the mouse and blow away when he sneezes.
- He gets sleepy if left alone for 30 seconds, and wakes up startled when you move.
- Typing line on the home screen and a hello that matches the visitor's time of day.
- Section headings scramble into place. Cards tilt under the mouse (desktop).
- Contact > "Save my CV as PDF": builds a one-page CV from content.js and opens the print dialog (choose Save as PDF).
- Ask me / command menu: Ctrl+K (Cmd+K on Mac) or "/". Prepared answers from content.js, not a live AI.
  Add your own answers in the "faq" list in content.js.
- Tickle the nose by clicking it, or type  achoo  anywhere. Sound is off by default (top bar).
- Sneeze counter and achievements, "Say bless you" reply, "Hear it" on each language card (uses the visitor's device voices).
- Six secrets to find. The Ask box shows how many have been found.
- Reduced-motion setting: the intro, embers and animations are turned off.

THE 3D FACE
- The face is a Roblox-style 3D character drawn live with WebGL (avatar3d.js). It needs no internet and no library.
- If a device cannot run WebGL2, the site shows the flat SVG face automatically.
- To force the SVG face, add ?face=svg to the address.
- avatar3d.js must sit in the same folder as index.html.
